## Lightweight conventions

- Track **subject**, **provenance** (standalone/fork), and **maintenance status** independently.
- Set maintenance status only after review: active, experimental, reference, or retired.
- Give each maintained repository a purpose sentence, setup command, entry point, and example output.
- Cross-link related projects; combine them only when their code and runtime belong together.
- Keep this public catalog limited to public information.
- Update the JSON and this page together when repositories are added or reclassified.

This catalog is documentation, not GitHub topic metadata or a profile README. It is hosted in ANEWFILES because that existing repository can be edited through the current connection.
